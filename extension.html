AntRouter for Chrome

← Back to the game

The extension is the same game as this website, shrunk into a popup so Mandu is one click away while you work in Claude, ChatGPT or Gemini. It isn't on the Chrome Web Store yet, so you load it yourself. That takes about a minute.

1. Install it

  1. Get the files. Download AntRouter (ZIP) and unzip it, or clone the GitHub repo.
  2. In Chrome, open chrome://extensions (paste it into the address bar).
  3. Turn on Developer mode (top right of that page).
  4. Click Load unpacked and choose the folder that contains manifest.json. In the ZIP that's the antrouter-main folder.
  5. Click the puzzle-piece icon in Chrome's toolbar and pin AntRouter so the anteater icon stays visible.

Working from the repo? powershell -ExecutionPolicy Bypass -File tools/package-extension.ps1 builds a trimmed copy in dist/antrouter-extension/ (load that folder instead) and a ZIP next to it.

2. Start it

Click the AntRouter icon in the toolbar. Mandu opens in a popup right away. There's no title screen in the extension, so you can route a prompt within seconds.

The popup closes when you click anywhere outside it. Your progress is saved, so it picks up where you left off next time.

3. Find your way around the popup

Top bar

Your level and crumbs, Settings, End session and the Light/Dark/System theme switch.

Prompt box

Choose the app you're working in (Any app, Claude, ChatGPT, Gemini), type a prompt or tap a sample (the samples scroll sideways), then press Route prompt or Ctrl + Enter (⌘ + Enter on a Mac).

Left side: Mandu

Watch him follow the trail and swallow an ant. Under him: Zot!, Pet Mandu, Nap and Wake up. The window lights hide him (red), minimize him (yellow) or expand him (green).

Right side: tabs

Route shows the pick, how sure Mandu is, the reroute chips, Good route, Second opinion and Open in…. Trails shows what he has learned, Progress your level, unlocks, badges and quests, Shop gear, and About a glossary of Mandu's words.

Keyboard: Tab moves between controls, and the arrow keys move between tabs.

Open in Claude and Open in ChatGPT open a new tab with your prompt already filled in. Gemini can't take a prompt through a link, so Open in Gemini copies it for you to paste.

4. How it differs from the website

  • No title screen, tour or core-loop strip. They're left out to fit the popup. Use the website to watch the tour.
  • Its own save. Chrome keeps the extension's storage separate from the website's. To bring your level across, open Settings → Move your save on one, press Copy my save code, then paste it into Settings on the other and press Load this code.
  • Same game otherwise. Levels, unlocks, crumbs, quests, Calm mode and sound all work the same.

5. Update it

Download a fresh ZIP (or pull the repo), replace the old folder, then go to chrome://extensions and click the circular reload arrow on the AntRouter card. Your save is kept as long as you reload the same extension rather than removing it.

6. If something looks wrong

The icon is missing
Pin it from the puzzle-piece menu.
"Manifest file is missing or unreadable"
You picked the wrong folder. Choose the one that has manifest.json directly inside it.
Music doesn't play
Turn it on in Settings (it's off by default). If you used the packaging script, run it again so Carefree.mp3 is included.
